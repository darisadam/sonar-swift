Override via env

SONAR_HOST_URL    SonarQube base URL
SONAR_SWIFT_BIND  Dashboard bind host (default 127.0.0.1)
SONAR_SWIFT_PORT  Dashboard port (default 8080)
SONAR_TOKEN       SonarQube auth token
