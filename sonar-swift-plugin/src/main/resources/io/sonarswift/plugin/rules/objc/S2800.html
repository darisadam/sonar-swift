Why is this an issue?

MD5 is cryptographically broken: collisions can be produced in seconds on commodity hardware. Do not use it for digital signatures, password hashing, or message authentication.

Noncompliant code example

unsigned char digest[CC_MD5_DIGEST_LENGTH];
CC_MD5(data.bytes, (CC_LONG)data.length, digest);   // Noncompliant

Compliant solution

unsigned char digest[CC_SHA256_DIGEST_LENGTH];
CC_SHA256(data.bytes, (CC_LONG)data.length, digest);
