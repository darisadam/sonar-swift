Why is this an issue?

A force-cast (as!) traps at runtime if the cast fails. Use conditional cast (as?) and handle the nil case explicitly.

Noncompliant code example

let cell = tableView.dequeueReusableCell(withIdentifier: "X", for: indexPath) as! MyCell  // Noncompliant

Compliant solution

guard let cell = tableView.dequeueReusableCell(
        withIdentifier: "X", for: indexPath) as? MyCell else {
    assertionFailure("Cell registration is broken")
    return UITableViewCell()
}
