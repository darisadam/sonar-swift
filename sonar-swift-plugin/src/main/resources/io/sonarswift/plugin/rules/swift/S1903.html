Why is this an issue?

UIKit, AppKit, and most of SwiftUI's view body work must happen on the main actor. Calling them from a non-main async context (a Task { … }, a background actor, a continuation callback) produces UI corruption, lost updates, or crashes.

Noncompliant code example

func loadProfile() async {
    let data = try await api.fetch()
    titleLabel.text = data.title       // Noncompliant — likely off main
}

Compliant solution

@MainActor
func loadProfile() async {
    let data = try await api.fetch()
    titleLabel.text = data.title       // OK — function is @MainActor
}

// Or hop explicitly:
func loadProfile() async {
    let data = try await api.fetch()
    await MainActor.run {
        titleLabel.text = data.title
    }
}
