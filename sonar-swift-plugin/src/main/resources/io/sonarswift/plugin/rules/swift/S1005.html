Why is this an issue?

print(), debugPrint(), and dump() write to stdout — they're useful during development but leak diagnostic detail into shipping binaries. They can also surprise performance-sensitive code paths by serialising large objects.

Noncompliant code example

func saveUser(_ user: User) {
    print("Saving \(user)")        // Noncompliant
    repository.save(user)
}

Compliant solution

import os

private let log = Logger(subsystem: "com.example.app", category: "users")

func saveUser(_ user: User) {
    log.debug("Saving \(user, privacy: .private)")
    repository.save(user)
}
