Why is this an issue?

try! traps at runtime if the call throws. Handle errors with do/catch or propagate them with try.

Noncompliant code example

let data = try! Data(contentsOf: url)  // Noncompliant

Compliant solution

do {
    let data = try Data(contentsOf: url)
    process(data)
} catch {
    logger.error("Failed to load: \(error)")
}
