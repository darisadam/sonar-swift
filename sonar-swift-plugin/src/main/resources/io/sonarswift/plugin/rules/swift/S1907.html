Why is this an issue?

A static var declared on a non-actor type is global mutable state — two threads can read and write to it simultaneously with no synchronization, which is a data race. Swift 6's strict concurrency mode rejects this by default.

Noncompliant code example

enum FeatureFlags {
    static var debugMode = false              // Noncompliant
}

Compliant solutions

// 1. If it's actually immutable, use `let`:
enum FeatureFlags {
    static let debugMode = false
}

// 2. If it must be mutable, move into an actor:
actor FeatureFlags {
    static let shared = FeatureFlags()
    var debugMode = false
}

// 3. If you've audited the synchronization yourself:
enum FeatureFlags {
    nonisolated(unsafe) static var debugMode = false   // see rule S1908
}
