Why is this an issue?

If a block captures {@code self} strongly and is also stored as a property of {@code self} (or owned indirectly), it creates a retain cycle that leaks the object.

Noncompliant code example

self.handler = ^{
    [self doSomething];      // Noncompliant — block retains self, self retains block
};

Compliant solution

__weak typeof(self) weakSelf = self;
self.handler = ^{
    __strong typeof(weakSelf) strongSelf = weakSelf;
    if (!strongSelf) return;
    [strongSelf doSomething];
};
