Why is this an issue?

MD5 is cryptographically broken: collisions can be produced in seconds on commodity hardware. It must not be used for any security-sensitive purpose (digital signatures, password hashing, message authentication, etc.).

Noncompliant code example

import CryptoKit

let digest = Insecure.MD5.hash(data: token)        // Noncompliant

// CommonCrypto direct use
CC_MD5(bytes, length, buffer)                       // Noncompliant

Compliant solution

import CryptoKit

let digest = SHA256.hash(data: token)

Exceptions

If used only for non-security checksumming on trusted input (e.g. file fingerprinting in build tools), suppress with // sonar-disable-next-line:S1804.
