Why is this an issue?

Plain-text HTTP traffic can be intercepted and modified by anyone on the network path. For any URL that carries user data or app state, use HTTPS so TLS protects the channel.

Noncompliant code example

let url = URL(string: "http://api.example.com/users")!  // Noncompliant

Compliant solution

let url = URL(string: "https://api.example.com/users")!

Exceptions

  • Localhost / loopback URLs (development)
  • Private-range IPs (10.x, 192.168.x, 172.16-31.x)
  • W3C XML namespaces and DTD references — these are identifiers, not endpoints
