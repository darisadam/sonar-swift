Why is this an issue?

Long methods are hard to read, hard to test, and tend to hide multiple responsibilities. The default threshold is 60 lines for Objective-C.

Noncompliant code example

- (void)processOrder:(Order *)order {
    // ... 80 lines ...
}

Compliant solution

- (void)processOrder:(Order *)order {
    [self validate:order];
    [self charge:order];
    [self fulfill:order];
    [self notify:order];
}
