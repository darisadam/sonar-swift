Why is this an issue?

Hardcoding a credential (API key, OAuth token, password) in source means it ships with every binary, appears in every commit, and is recoverable by anyone with the IPA. Once leaked it requires rotation across every dependent system.

Noncompliant code example

struct API {
    static let key = "AKIAIOSFODNN7EXAMPLE"        // Noncompliant — AWS access key
    static let token = "ghp_aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789"  // Noncompliant — GitHub PAT
}

Compliant solution

struct API {
    static var key: String {
        ProcessInfo.processInfo.environment["MY_API_KEY"]
            ?? loadFromKeychain("MY_API_KEY")
            ?? abort("Missing MY_API_KEY")
    }
}

Possible delivery mechanisms for app secrets:

  • Server-issued, short-lived OAuth/JWT after user authentication
  • Configuration provided at build time via Xcode build settings + xcconfig, never committed
  • Remote configuration (Firebase Remote Config, AWS AppConfig) with appropriate access controls
