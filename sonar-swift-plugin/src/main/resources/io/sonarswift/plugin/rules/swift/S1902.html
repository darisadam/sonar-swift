Why is this an issue?

An actor guarantees serial access to its mutable state, but only when that access goes through its isolation barrier. Reading or writing an actor property from outside without await is a compile error under Swift 6 strict concurrency, and a runtime data-race warning before that.

Noncompliant code example

actor Counter {
    var value = 0
}

func bump(_ c: Counter) {
    c.value += 1     // Noncompliant — racing access
}

Compliant solution

actor Counter {
    var value = 0
    func bump() { value += 1 }
}

func bump(_ c: Counter) async {
    await c.bump()
}
