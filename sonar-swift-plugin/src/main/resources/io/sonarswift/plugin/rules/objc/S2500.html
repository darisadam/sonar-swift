Why is this an issue?

{@code ==} on two {@code NSNumber*} compares pointer identity, not numeric equality. Use {@code isEqualToNumber:} or {@code compare:} for value comparison.

Noncompliant code example

NSNumber *a = @1;
NSNumber *b = @1;
if (a == b) { /* may be true OR false depending on tagged-pointer optimization */ }  // Noncompliant

Compliant solution

if ([a isEqualToNumber:b]) { ... }
